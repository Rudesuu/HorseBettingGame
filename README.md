# Horse Betting
A horse racing game made with Java Swing.

## Requirements
- Apache NetBeans (JDK 26)
- Dependency: Gson 2.13.2 (declared in pom.xml)

## Build and run with Apache NetBeans
1. Unzip the submission.
2. In Apache NetBeans, choose File > Open Project and select the project folder.
3. Check if Apache NetBeans uses JDK 26 (Tools > Java Platforms).
4. In the Projects tab, right-click the project and choose Run or press F6.
